# #ГРОМКО — Dark Neon Nightlife & Karaoke Experience 🎤🍸

Сайт караоке-бара **#ГРОМКО** (г. Иваново, ул. 10 Августа, 43), выполненный по концепции **Dark Neon**:
> **«Музыка → свет → люди → алкоголь → еда → пение → ночь»**

---

## 🌟 Ключевые особенности

- **Dark Neon Палитра:** 80% глубокого графита (`#050507`, `#09090D`, `#101017`) + 20% неона (`#FF00AC` Pink, `#08CEFD` Cyan, `#7C3CFF` Violet) с мягкими radial glow и glassmorphism.
- **Типографика:** `Unbounded` для акцентных клубных заголовков + `Manrope` для удобного чтения интерфейса.
- **Hero-секция:** Полноэкранный атмосферный блок с живым статусом `● OPEN NOW` (динамический расчет текущего дня недели) и быстрым переходом к бронированию или фото.
- **Neon Marquee:** Бесконечная плавная строка между секциями.
- **«Этой неделей в #ГРОМКО» (Расписание и акции):**
  - *Desktop:* 7-колоночный календарь (ПН—ВС) с интерактивным раскрытием программы дня и кнопкой быстрой брони.
  - *Mobile:* Горизонтальный свайп недели с крупной активной карточкой дня.
- **Фотогалерея:**
  - *Desktop:* Асимметричный masonry-layout с ритмическими словами `SING`, `DANCE`, `DRINK`, `REPEAT`.
  - *Mobile:* Кинематографичный touch-карусель со счетчиком слайдов `01 / 08`.
  - Полноэкранный **Lightbox** для просмотра фото в высоком разрешении.
- **Кухня и Барная карта:**
  - Презентация хитов («Black Truffle Gromko Burger», «Neon Velvet Signature Cocktail»).
  - На мобильных: удобный переключатель `[ ЕДА ] [ БАР ]`.
  - Полный модальный каталог меню с фильтрацией по категориям.
- **Система Бронирования:**
  - *Desktop:* `ГОТОВЫ ПЕТЬ?` — интерактивная сетка слотов времени (`Свободно` / `Занято` / `Выбрано с неоновым градиентом`), выбор даты, количества гостей и моментальная валидация.
  - *Mobile:* 4-шаговый визард / мини-приложение (`1. Когда?` → `2. Во сколько?` → `3. Сколько вас?` → `4. Контакты`) со статусом `X / 4` и кнопкой возврата.
  - Модальное окно подтверждения брони с присвоением ID.
- **Контакты и Карта:**
  - Интерактивная тёмная карта с неоновым маркером заведения и ссылкой в Яндекс.Карты.
  - На мобильных — кнопки быстрого звонка `[ ПОЗВОНИТЬ ]` и построения маршрута `[ ПОСТРОИТЬ МАРШРУТ ]`.
- **Sticky Mobile CTA:** Плавающая неоновая кнопка бронирования внизу экрана на смартфонах.
- **API Бэкенд:** Express.js сервер с эндпоинтами для акций, меню, бара, галереи и броней.

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
bun install
# или
npm install
```

### 2. Запуск фронтенда в режиме разработки (Vite)
```bash
npm run dev
# Порт: http://localhost:3000
```

### 3. Запуск бэкенд API сервера (Node.js / Express)
```bash
npm run server
# Порт: http://localhost:3001
```

### 4. Сборка для продакшена
```bash
npm run build
```

## 📸 Как заменить фотографии и данные на свои

Все текстовые данные, меню, расписание, контакты и ссылки на фотографии находятся в одном файле:
👉 `src/data/mockData.ts`

- Чтобы изменить фото Hero: отредактируйте `HeroSection.tsx` или `src/data/mockData.ts`.
- Чтобы изменить позиции меню: массив `MENU_ITEMS` в `src/data/mockData.ts`.
- Чтобы изменить коктейли и бар: массив `BAR_ITEMS` в `src/data/mockData.ts`.
- Чтобы добавить свои фотографии в галерею: массив `GALLERY_PHOTOS` в `src/data/mockData.ts`.
- Чтобы изменить телефон, адрес и соцсети: объект `VENUE_INFO` в `src/data/mockData.ts`.
